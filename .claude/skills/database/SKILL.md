# Database — DeshiA

SQLite via **Drizzle ORM** + **better-sqlite3**, running in the Next Node
runtime (never the browser — `db/client.ts` throws if `window` exists).

## Files
- `src/db/schema/tables.ts` — all tables + inferred row types.
- `src/db/client.ts` — singleton connection (WAL, FKs ON, busy_timeout).
- `src/db/repositories/*.ts` — the **only** place that touches the DB.
- `src/db/migrations/*` — generated by `pnpm db:generate`; applied by
  `pnpm db:migrate` (`src/db/migrate.ts`).

## Entities
Workspace · Image · Annotation · BoundingBox · AnnotationEvent · ExportJob.
Class/View/Component are **string keys**, resolved against a versioned
`AnnotationSchema` — the ontology is NOT in the schema tables.

## Rules
- Foreign keys ON; every FK indexed; timestamps epoch ms.
- Image status `PENDING|IN_PROGRESS|ANNOTATED|SKIPPED|ERROR`; annotation status
  `DRAFT|SUBMITTED` with an integer `annotationVersion`.
- **`annotation_events` is append-only** — the audit + recovery log. Do not
  delete annotation history; soft-archive via a new event.
- Every multi-row write is a **transaction** (`sqlite.transaction(...)` /
  drizzle `db.transaction`). Partial writes must never leave inconsistent state.
- Output numbering uses persistent `images.datasetIndex`, never a directory
  file count.
- Access DB only through repositories; no raw SQL or Drizzle calls in
  features/components.

## Migrations
Change `tables.ts` → `pnpm db:generate` → review SQL in `db/migrations` →
`pnpm db:migrate`. **Never edit an already-applied migration**; add a new one.
